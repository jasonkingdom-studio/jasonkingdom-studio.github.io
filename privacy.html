개인정보처리방침

시행일: 2026년 10월 25일

1. 대상

이 방침은 JASON KINGDOM STUDIO(대표 김재성, 이하 "스튜디오")의 홈페이지 jasonkingdom.com과, 스튜디오가 자체 채널 운영에 쓰는 내부 앱 JK Secretary(Google OAuth 클라이언트)에 적용됩니다.

2. JK Secretary가 접근하는 정보

JK Secretary는 스튜디오가 직접 소유·운영하는 YouTube 채널에만 연결되며, 사용자가 Google 로그인 화면에서 허용한 범위 안에서 다음 정보를 사용합니다.

  • YouTube 계정·채널 기본 정보(채널 이름, 구독자 수, 영상 목록)
  • YouTube 분석 보고서(조회수, 시청 시간 등 통계)
  • YouTube 동영상 관리: 채널 운영자가 승인한 영상의 업로드·예약·썸네일 설정

Google 계정 비밀번호는 받지 않으며, 접근 토큰은 운영자의 PC에만 저장됩니다.

3. 이용 목적

  • 스튜디오 채널의 영상 업로드·예약 공개
  • 공개 후 48시간·7일 성과 분석과 콘텐츠 개선

수집한 정보를 광고, 판매, 제3자 제공에 쓰지 않습니다.

4. 보관과 삭제

분석 결과는 운영자의 PC에만 보관하며 목적을 다하면 지웁니다. 언제든지 Google 계정 > 보안 > 서드 파티 액세스에서 JK Secretary의 접근 권한을 철회할 수 있습니다.

JK Secretary의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다. YouTube 데이터 이용에는 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

5. 홈페이지 상담 문의

홈페이지 상담 폼으로 받은 이름·연락처·문의 내용은 답변과 상담에만 사용하고, 상담이 끝나면 지체 없이 지웁니다.
